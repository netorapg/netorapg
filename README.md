**Software engineer from Brazil.** I build mobile apps and the backends behind them. I like knowing how things work underneath, so I wrote a 2D game engine from scratch in C++ and published a paper about it.

- 🔧 Mobile & backend developer on the **ProComércio ERP** ecosystem: Flutter, .NET 8, SQL Server, Docker
- 🎓 B.S. in Software Engineering (IFPR) · M.Sc. student in Computer Science (UEL)
- 📄 Three peer-reviewed papers, one of them about that game engine
- 🐧 Linux on every machine I own (Arch, Fedora)
